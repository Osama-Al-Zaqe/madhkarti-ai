# مذاكرتي AI

منصة عربية متجاوبة لإدارة ال��نهج، الجدول، الامتحانات، الملفات، المؤقت، والتقدم الدراسي للطلاب في مصر.

## ما الذي تم تنفيذه

- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- لوحة تحكم رئيسية مع التاريخ والساعة والمهام والأهداف.
- إعداد ملف الطالب مع السنة الدراسية والنظام والشعبة والمواد.
- إدارة المواد والأبواب والدروس مع حالات الدورة وملخصات مفسرة.
- لوحة جدولة يومية وأسبوعية مع جدولة تلقائية ومهام يدوية.
- إدارة المهام اليومية والأهداف long-term.
- جدول امتحانات مع عد تنازلي وتسجيل النتائج.
- مؤقت تركيز بومودورو مع سجل جلسات.
- مراجعة وتكرار متباعد.
- إحصائيات للتقدم والإنجاز.
- مكتبة للملفات والمصادر.
- مساعد ذكي محلي (قواعد محلية) مع إعداد مزود بديل.
- دعم PWA + Service Worker للعمل دون اتصال عند التحميل المسبق.
- حفظ البيانات محليًا عبر localStorage مع تصدير/استيراد JSON.

## التشغيل

### 1) الوصول إلى المشروع

افتح المجلد المشروع ثم استخدم خادم ثابت محلي:

```bash
cd /path/to/madhkarti-ai
python3 -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

### 2) التحديثات التقريبية

- لا توجد تبعيات إضافية مطلوبة لأن التطبيق يعمل كـ static HTML/CSS/JS.
- استخدم Browser DevTools لفحص القيم المحلية أو استيراد/تصدير البيانات.

## ملاحظات مهمة

- البيانات الحالية في التطبيق عبارة عن بيانات تجريبية توضيحية فقط، ومصممة ليتم استبدالها بمناهج رسمية عند توفرها.
- المساعد الذكي الحالي يعمل محليًا وفق قواعد داخلية؛ لا يتطلب مفتاح API.
- لإضافة مزود ذكاء اصطناعي خارجي لاحقًا، استخدم نموذج بديل من قسم الإعدادات.

## طريقة تحديث المناهج لكل سنة دراسية

1. أضف السنة الدراسية من قسم الملف الدراسي.
2. اختر الشعبة والمسار المناسبة.
3. أضف المواد ثم الوحدات والأبواب والدروس.
4. لكل درس أدخل:
   - ملخص قصير
   - الفكرة الأساسية
   - الموضوعات الرئيسية
   - ما الذي يفهمه الطالب بعد الدراسة
   - العلاقة بالأجزاء السابقة/اللاحقة
   - المتطلبات السابقة
5. استبدل البيانات التجريبية عند توفر بيانات رسمية من المدارس أو الوزارة.

## طريقة حفظ البيانات ونسخها احتياطيًا

- يتم حفظ البيانات تلقائيًا في المتصفح عبر localStorage.
- يمكن التصدير إلى ملف JSON من قسم الإعدادات.
- يمكن استيراد النسخة الاحتياطية مرة أخرى من نفس القسم.
- عند حذف الحساب داخل التطبيق لا توجد سياسة خادم، لذلك تبقى البيانات فقط على الجهاز الحالي حتى يتم التصدير أو الحفظ.

## نصائح للأمان والخصوصية

- لا تحفظ كلمات المرور أو مفاتيح API داخل الواجهة الأمامية.
- لا تضع أي مفتاح أو سر داخل الكود في المشروع.
- عند ربط مزود خارجي لاحقًا، أنشئ نقطة إرسال إلى الخادم وليس مبا��رة من المتصفح.

## خطة التطوير القادمة

- مزامنة الحساب بين الأجهزة عبر خادم.
- دعم تسجيل الدخول عبر حسابات آمنة.
- مزود ذكاء اصطناعي خارجي قابل للتبديل.
- استيراد بيانات مناهج رسمية بتنسيق موحد.
- واجهات API ونسخ احتياطي عبر السحابة.
